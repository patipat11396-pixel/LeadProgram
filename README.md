# Lead Tracker

โปรแกรมติดตาม Lead แบบไฟล์เดียว (`public/index.html`) ไม่ต้องติดตั้งอะไร — ดับเบิลคลิกเปิดในเบราว์เซอร์ได้เลย

## ใช้งาน
| แท็บ | ใช้ทำอะไร |
|---|---|
| ✅ ต้องทำ | งานที่เลยกำหนด / วันนี้ / ภายใน 7 วัน + จำนวน Lead แต่ละสถานะ |
| 👥 Leads ทั้งหมด | ค้นหา กรองตามสถานะ เปิดดูประวัติการคุย |
| 📞 Hit List | รายชื่อที่ยังไม่มีเบอร์ → ค้น Google → วางเบอร์ → บันทึก |
| 💾 สำรองข้อมูล | ดาวน์โหลด/นำเข้าไฟล์สำรอง (.json), ส่งออก Excel (.csv) |

**ทุกครั้งที่คุยกับลูกค้า:** เปิด Lead → เขียน Log ว่าคุยอะไร → ใส่ "ขั้นต่อไป" + วันที่ → กด "บันทึก Log"
ระบบจะย้าย Lead ไปอยู่ในแท็บ "ต้องทำ" ตามวันที่ที่ตั้งไว้

## ข้อควรรู้
ข้อมูลเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น — ไม่ sync ข้ามเครื่อง
และจะหายถ้าล้างข้อมูลเบราว์เซอร์ ให้กดดาวน์โหลดไฟล์สำรองสม่ำเสมอ (โปรแกรมจะเตือนถ้าเกิน 7 วัน)

## Deploy (Cloudflare Workers)
`wrangler.jsonc` ตั้งค่าให้ deploy โฟลเดอร์ `public/` เป็นเว็บแบบ static — Build command: ไม่ต้องมี, Deploy command: `npx wrangler deploy`
