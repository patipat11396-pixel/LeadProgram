# Lead Tracker

โปรแกรมติดตาม Lead แบบไฟล์เดียว (`public/index.html`) ไม่ต้องติดตั้งอะไร — ดับเบิลคลิกเปิดในเบราว์เซอร์ได้เลย

## ใช้งาน
| แท็บ | ใช้ทำอะไร |
|---|---|
| ✅ ต้องทำ | งานที่เลยกำหนด / วันนี้ / ภายใน 7 วัน + จำนวน Lead แต่ละสถานะ |
| ⭐ ลูกค้าปัจจุบัน | ลูกค้าที่ปิดการขายแล้ว (สถานะ "ลูกค้าปัจจุบัน") แยกจาก Lead พร้อมสินค้า (Item) และงานที่ต้องตามต่อ |
| 👥 Leads | ตารางโชว์ ลูกค้า / สถานะ / ทำอะไรอยู่ / ต้องทำอะไรต่อ / ภายในวันที่ + นำเข้า/ส่งออก Excel |
| 📞 Hit List | รายชื่อที่ยังไม่มีเบอร์ → ค้น Google → วางเบอร์ → บันทึก |
| 💾 สำรองข้อมูล | ดาวน์โหลด/นำเข้าไฟล์สำรอง (.json), นำเข้า/ส่งออก Excel, ไฟล์ Excel ตัวอย่าง |

**ทุกครั้งที่คุยกับลูกค้า:** เปิด Lead → เขียน Log ว่าคุยอะไร → ใส่ "ขั้นต่อไป" + วันที่ → กด "บันทึก Log"
ระบบจะย้าย Lead ไปอยู่ในแท็บ "ต้องทำ" ตามวันที่ที่ตั้งไว้

## นำเข้า Excel
รองรับ .xlsx / .xls / .csv — ระบบเดาว่าคอลัมน์ไหนคือ ชื่อ, สถานะ, ทำอะไรอยู่, ต้องทำต่อ, วันที่ ฯลฯ จากหัวตาราง
(แก้เองได้ก่อนกดนำเข้า) อ่านวันที่แบบ วัน/เดือน/ปี, พ.ศ., "5 พ.ย. 69" ได้ และเติมเลข 0 หน้าเบอร์ที่ Excel ตัดทิ้ง
ลูกค้าซ้ำ (เบอร์เดียวกัน หรือ ชื่อ+บริษัทเดียวกัน) เลือกได้ว่าจะอัปเดต / ข้าม / เพิ่มใหม่
ตัวอ่าน Excel: SheetJS 0.20.3 (`public/vendor/xlsx.full.min.js`, Apache-2.0)

## กันข้อมูลซ้ำ
ตอนนำเข้า / เพิ่ม Lead / Hit List ระบบเทียบกับข้อมูลเดิม: อีเมล, เบอร์ (ต่างรูปแบบก็จับได้), LINE, ชื่อ
(ตัด Co., Ltd. / บริษัท / จำกัด ออก และเทียบชื่อในวงเล็บ) — ตรงกันชัดเจนจะรวมให้อัตโนมัติ
ชื่อคล้ายกันจะแจ้งให้เลือกเอง และมีปุ่ม "ตรวจหารายการซ้ำ" ในแท็บตั้งค่าเพื่อรวมรายการที่ซ้ำอยู่แล้ว

## เชื่อม Outlook
ดึงอีเมลที่คุยกับลูกค้า (Microsoft 365) มาแสดงในหน้าลูกค้า และบันทึกเป็น Log ได้ — อ่านอย่างเดียว
ตั้งค่าครั้งแรกตาม [SETUP-OUTLOOK.md](SETUP-OUTLOOK.md) (ใช้ MSAL.js 4.30.0, MIT — `public/vendor/msal-browser.min.js`)

## ข้อควรรู้
ข้อมูลเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น — ไม่ sync ข้ามเครื่อง
และจะหายถ้าล้างข้อมูลเบราว์เซอร์ ให้กดดาวน์โหลดไฟล์สำรองสม่ำเสมอ (โปรแกรมจะเตือนถ้าเกิน 7 วัน)

## Deploy (Cloudflare Workers)
`wrangler.jsonc` ตั้งค่าให้ deploy โฟลเดอร์ `public/` เป็นเว็บแบบ static — Build command: ไม่ต้องมี, Deploy command: `npx wrangler deploy`
